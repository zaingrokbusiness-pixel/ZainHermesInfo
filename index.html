Radar Backups

Radar Backups is a private backup tool operated by Zain for his own Etsy research database. It uses rclone to store encrypted database backups in his own Google Drive account.

What the tool does

It creates a database backup, uploads the encrypted backup to Google Drive, downloads it for integrity and restore checks, and removes older backup sets only after verification succeeds.

Who can use it

This is an owner-operated tool, not a public sign-up service. It does not request access to other people's Google accounts. Google authorization is used to connect the operator's own Google Drive account.

This website provides information only. It does not host the research application, database, backups, Google credentials, or authorization tokens.
