Radar Backups Privacy Policy

This policy describes the intended operation of Radar Backups, a private tool operated by Zain for his own research-database backups.

Google account access and use

The operator authorizes rclone to access his Google Drive account. The backup workflow uses this access to list backup objects, upload encrypted backup files and verification files, download them for integrity and restore checks, and delete older backup sets after a new backup passes verification.

The underlying Google Drive authorization may allow broader file access than this workflow needs. This policy describes the backup workflow; it does not claim that Google's permission grant is technically restricted to a single backup folder.

Storage and security

Backups are encrypted by rclone's crypt remote before being stored in Google Drive. Verification temporarily restores downloaded backups in a local scratch database. Authorization tokens, configuration, and encryption secrets are stored on the operator's devices, not on this public website or in its repository.

Sharing and other uses

The tool is not intended to sell Google user data, use it for advertising, or use it to train AI models. Backup files are transmitted to Google Drive for storage and downloaded to the operator's device for verification or recovery. Google processes the account and stored objects under its own terms and privacy policy.

Retention and control

Successful backup rotation retains the newest verified backup set locally and in the configured cloud destination. Failed verification can leave older or incomplete sets in place to avoid deleting the last usable backup. Local verification uses temporary files and databases.

The operator can revoke the app's access through Google Account security settings. Revoking access does not itself delete previously stored backups; those must be removed separately when no longer needed.

This informational website
