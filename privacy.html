Privacy Policy

Last updated: October 18, 2026.

Zain Hermes is a private application operated by Zain for managing his own Google Drive files and YouTube account. It is not a public sign-up service. This policy describes how the application accesses, uses, stores and shares data. The owner must read and accept it before use.

Google Drive data

With the owner's authorization, the application accesses file and backup information needed to list, upload, download and verify personal backups, and to remove older backup sets within an approved workflow. The current backup workflow encrypts backup contents before cloud storage. Google Drive permissions may allow broader access than the particular files used by that workflow; they are not necessarily restricted to a single folder.

YouTube data

The application uses YouTube API Services, including YouTube Data API v3 and YouTube Analytics API. It accesses the authorized owner's channel identifiers, channel information, statistics and non-monetary analytics, such as views, watch time and subscriber changes. This information supports account verification, personal performance review and content planning.

The current scopes are youtube.force-ssl and yt-analytics.readonly. The first scope technically permits viewing, editing and permanently deleting certain YouTube content; it is not an upload-only permission. The current connector implements read-only checks, not content modification or deletion.

Future owner-authorized uploads and content management may process video files, thumbnails, titles, descriptions, tags and publication settings. These operations have not yet been implemented or tested. If enabled, publishing publicly would make the selected content and metadata public on YouTube. No monetary analytics scope is requested.

Storage and security

Credentials, authorization tokens and operational reports are stored on owner-controlled devices or servers with restricted filesystem access, not on this public website or in its repository. YouTube credentials are kept separately from backup credentials. Google API requests use HTTPS. Restricted file access is not a claim that all local data is encrypted at rest. The application does not collect Google passwords.

Processing and sharing

Google receives authorization requests, API requests and content sent to its services, under its own terms and privacy policy.

Necessary channel identifiers, statistics and report excerpts may be sent to the owner's AI assistant provider for requested analysis and recommendations, and may appear in the owner's chat service. The current setup uses OpenAI-backed Hermes and Slack; reports have been processed through that assistant workflow. Provider retention depends on the applicable service terms and settings; zero retention is not claimed. Credentials and tokens must not be included in those conversations.

Google user data is not sold or used for advertising. The owner does not authorize its use to develop, improve or train generalized AI or machine-learning models. Processing report excerpts to generate an answer is distinct from training a model. Any future provider or use requires review against the applicable Google data-use policies. Backup contents are not intentionally shared with AI providers by the backup workflow.

Retention and deletion

The backup workflow retains the newest verified backup set; failed verification may leave additional files to protect the last usable backup. Revoking access does not automatically delete files already stored in Google Drive.

YouTube data is retained only as needed for the authorized purpose. Stored channel metadata and statistics must be refreshed or deleted within 30 calendar days. Authorized analytics may be retained longer only where YouTube policies and ongoing owner consent permit. Tokens are retained while the connection remains authorized. Retention review and cleanup are currently manual; automatic cleanup and periodic authorization checks are not implemented.

To request deletion or withdraw consent, contact zaingrok.business@gmail.com. The operator will stop the affected processing and delete associated stored YouTube data as soon as possible and within seven calendar days of a deletion request or direct withdrawal of consent. Following revocation through Google Account settings, associated API data must be deleted as soon as possible and within 30 calendar days. Copies in chat or AI-provider systems must also be addressed through the applicable deletion controls; deleting a local report does not erase those copies. These are operator-managed obligations, not automated guarantees.

Deleting the application's stored data does not delete videos or other content held by YouTube. Use YouTube's own controls to manage that content.

Revoking Google access

The owner can revoke access through Google Account third-party permissions. Review the affected app grants carefully: Drive and YouTube clients share a Google Cloud project, so revocation should not be assumed to affect only one workflow.

This website

These static pages contain no login, tracking cookies, analytics scripts, advertising or embedded YouTube player. GitHub Pages hosts the site and may process request information under GitHub's privacy statement.

Terms and contact

Use of the YouTube integration is subject to the YouTube Terms of Service. Google's processing is described in the Google Privacy Policy.

For privacy questions, complaints or deletion requests: zaingrok.business@gmail.com.
